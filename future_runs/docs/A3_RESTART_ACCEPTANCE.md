## 检查口径

462 个数值变量（共 464）。462 个带 `_FillValue = 1e36`，所有统计**先屏蔽填充值**
再计算；填充点与 NaN 分开计数，只有**有效点上的 NaN/Inf** 算缺陷；
非负性按各变量自身量级的 `1e-9` 容差判定，而不是绝对零。
21 个变量全为填充（已记录，不当作通过）。

## 结果

### 1. NaN —— 存在，但是既有的，A3 没有引入

| 变量 | 新 | 旧 | NaN 掩膜是否相同 |
|---|---|---|---|
| `tempavg_finrw` | nvalid 1,226,904，NaN 1,150,984 | 同 | **True** |
| `tempavg_somhr` | nvalid 1,226,904，NaN 1,150,984 | 同 | **True** |
| `tempavg_agnpp` / `bgnpp` | NaN 0 | NaN 0 | True |

`1,226,904 − 1,150,984 = 75,920`，**正好等于 gridcell 数**——这两个累加量只在
每个 gridcell 的一个 column 上有定义，其余为 NaN。结构性的，新旧完全一致，
且已完成的 174 年历史运行就是带着它跑完的。**记录为既有观察，不阻塞 A3。**

### 2. `T_SOISNO min = 0` —— 是雪层，不是土壤层

| 层 | nvalid | min | max | 恰好为 0 的点 |
|---|---|---|---|---|
| 雪层 1–5 | 459,580 | 0 | 273.15 | 436,500（**94.98%**） |
| 土壤层 6–20 | 11,570,760 | **270.426** | **301.666** | **0** |

`T_SOISNO` 的维度是 `levtot=20`（5 雪 + 15 土壤），未激活的雪层按约定填 0。
土壤层没有任何一个 0，范围完全正常。**是我 spotlight 的边界对 `levtot` 变量
设错了，不是数据有问题。**

### 3. 关键碳水库 —— 域总量几乎不动

| 库 | 变化格点比例 | 单点 max rel | **域总量相对变化** |
|---|---|---|---|
| `totcolc`（总柱碳） | 6.2% | 8.9e-06 | **+8.7e−08** |
| `deadstemc` | 2.7% | 2.5e-05 | −7.3e−08 |
| `soil4c_vr` | 3.8% | 9.6e-07 | −3.7e−08 |
| `soil3c_vr` | 4.0% | 6.2e-06 | +3.1e−07 |
| `cwdc_vr` | 4.0% | 1.3e-05 | +1.2e−06 |
| `leafc` | 2.8% | 7.7e-05 | −1.5e−06 |
| `soil2c_vr` | 4.1% | 2.4e-04 | −9.9e−06 |
| `soil1c_vr` | 4.1% | 1.3e-03 | +1.4e−05 |
| `solutionp_vr` | 4.1% | 6.1e-06 | −1.2e−08 |
| `sminn_vr` | 4.1% | **0.846** | −5.5e−05 |

**域内总碳 `totcolc` 相对变化 8.7e−08**，即到 7 位有效数字不变。
这正是"2023 年末最后约 3 小时气象改变"应当产生的量级。

`sminn_vr` 单点 maxrel 0.846（某个点的矿质氮近乎减半），但域总量只动
5.5e−05。矿质氮是天尺度周转的小快库，单点摆动属预期。**记录，不阻塞。**

### 4. 220/464 个变化变量的性质

`maxrel > 0.5` 的 63 个，几乎全部是**绝对量极小**或**开关型**的场：

- `tempavg_finrw` 值域 [0, 1.8e−09]、`tempavg_somhr` [0, 5.7e−09]
- `tempsum_npp` [−1.7e−04, 4.1e−04]、`col_lag_npp` [−1.9e−05, 1.8e−05]
- `H2OSFC`/`FWET`/`H2OCAN`/`FINUNDATED`/`CONC_CH4_*`/雪相关场：
  `maxrel = 1` 只表示某些点从 0 变成非 0 或反之

慢库（`deadstemc`/`soil*c_vr`/`totcolc`）全部落在这 63 个之外，
其单点 maxrel 在 1e−06 ~ 1e−03。

分布形态与"末端快响应地表状态改变、年内累加量随之改变、慢库几乎不动"
一致。
