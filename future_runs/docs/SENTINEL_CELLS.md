# 194 个格点读到海洋 sentinel —— 调查结果

作业 516084（516078 是同一调查的第一版，其第 5 节结论无效，见文末）。
全程只读。

## 结论摘要

**机制已定性**：ELM 域网格与 TESSFA2 气象网格之间存在**均匀的半格偏移**，
而 cpl_bypass 的最近邻匹配**不检查匹配到的气象点是否有效**。这 194 个格点
就是这个普遍偏移恰好跨过陆/海边界的那一批。

**对域总量的影响为零**，但这不是因为格点少，而是因为**这些格点在模型里
已经是死的**——GPP 恒为 0，生物量近乎为 0。

## 1. 数量与位置

```
活跃陆地格点        75,920
读到 sentinel        194     (0.2555% 按格点数)
lat 25.5208 .. 37.4792      lon -94.9792 .. -76.3958
```

分布横跨整个域，不集中在某一角。

## 2. 面积加权占比（不是格点数）

```
活跃陆地总面积 (AREA × LANDFRAC_PFT)   1,345,210 km²
其中 sentinel 格点                        3,148.6 km²
面积加权占比                              0.2341%
```

它们的 `LANDFRAC_PFT`：min 0.25，中位数 **1.00**，max 1.00；
低于 0.5 的只有 24 个。**多数是整格陆地，不是零碎的海岸残片。**

## 3. 海岸、岛屿还是边界

```
到域边界的距离（格点数）：  = 0 : 167     ≤ 1 : 167    ≤ 2 : 168    ≤ 10 : 171
3×3 邻域内非活跃格点数：    min 3   中位数 3   max 6
完全位于内部（0 个非活跃邻居）：0 / 194
```

**167 个正好在域边界上，194 个全部至少有 3 个非活跃邻居，没有一个在内部。**
即全部是海岸线或域边缘格点。

## 4. 为什么会匹配到无效点 —— 半格偏移，不是缺数据

`lnd_import_export.F90` 对每个 ELM 格点在 zone_mappings 的 225,625 行里按
度数欧氏距离找最近点，**没有任何"该点是否有数据"的检查**：

```fortran
do g3 = 1,ng
  thisdist = 100*((latixy(g3) - ldomain%latc(g))**2 + &
                  (longxy(g3) - ldomain%lonc(g))**2)**0.5
  if (thisdist .lt. mindist) then
    mindist = thisdist ; ztoget = zone_map(g3) ; gtoget = grid_map(g3)
```

实测的匹配距离：

| 对象 | min | 中位数 | max |
|---|---|---|---|
| 这 194 个格点 | 0.02899 | 0.02946 | 0.02947 |
| **随机抽样的 4,218 个活跃格点** | **0.02899** | **0.02923** | **0.02947** |
| 气象网格半对角线（dlat=dlon=0.042） | — | **0.029698** | — |

**两者分布相同，且都约等于半对角线。** 也就是说全部 75,920 个格点都离
最近气象点约半格——两套网格在经纬两个方向上各偏移半格。这 194 个并没有
"离得更远"或"附近没有数据"；**它们只是这个普遍偏移恰好落到海洋侧的那些**。

194 个格点匹配到 137 个不同的气象行（有重复匹配）。

## 5. 七个变量里哪些是 sentinel

在第一条 2024 记录（record 2920）上，按**原始短整型**比较：

| 变量 | 原始 sentinel | 解码后 | 命中 |
|---|---|---|---|
| TBOT | 22725 | 396 K | 182 / 194 |
| PSRF | −23831 | −9999.1 Pa | 182 / 194 |
| QBOT | −14592 | 0.0010156 | 182 / 194 |
| FSDS | −30984 | −1111 W/m² | 182 / 194 |
| PRECTmms | −32768 | −0.088 | 182 / 194 |
| WIND | −14600 | −0.00134 | 182 / 194 |
| FLDS | 14924 | 1001 W/m² | 182 / 194 |

```
七个变量全部 sentinel : 182 个格点
任意一个 sentinel     : 182 个格点
```

两个数相同：**要么整行是海洋（七个全 sentinel），要么整行有效**，没有中间态。
TBOT 解码后 396 K 被 `min(...,323)` 钳成 323，PSRF 解码 −9999 Pa 被
`max(...,40000)` 钳成 40000——与实测的钳位现象吻合。

**⚠️ 剩下 12 个格点未解释。** 它们在 T1 的 48 小时里触到 TBOT=323，但其匹配行
在 record 2920 上不是 sentinel。可能是在别的记录上是 sentinel，也可能是别的
原因。**未查清，如实记录。**

## 6. 对碳通量的贡献 —— 零，因为这些格点是死的

生产历史运行 2023 年 h0，面积加权：

| 量 | 域总量 | sentinel 格点 | 占比 | sentinel 格点均值 vs 其余 |
|---|---|---|---|---|
| GPP | 92.63 | **0** | 0.0000% | **0** vs 6.90e−05 |
| NEE | −2.953 | 2.44e−07 | 0.0000% | 7.78e−11 vs −2.24e−06 |
| TOTVEGC | 1.223e+10 | 452.7 | 0.0000% | **0.142** vs **9140.4** |
| TLAI | 5.467e+06 | 0.0258 | 0.0000% | 8.16e−06 vs 4.075 |

**GPP 恒为 0，TOTVEGC 是域均值的 1/64000。** 这些格点没有植被、没有生产力——
在 323 K / 40 kPa 的驱动下植被无法存活。

所以：**域总量层面的影响可以忽略，但原因是这些格点被完全废掉了，
而不是它们的贡献被稀释了。** 0.23% 的陆地面积在模型里是死区。

## 7. 待决策（不由本文件决定）

三条路，代价差别很大：

**(a) 改最近邻匹配**，让它跳过 sentinel 行、选最近的有效点。
改 `lnd_import_export.F90`。半格偏移下有效点就在一格之内，所以修得动。
代价：源码改动要重新走 T1/T2 级别的验证；**并且会改变历史运行的结果，
A3 初始场随之作废，174 年历史要重跑**。

**(b) 把这 194 个格点从 ELM 域里屏蔽掉**。改 domain 文件。
代价：活跃格点数从 75,920 变化，**A3 初始场同样作废**，历史要重跑。

**(c) 接受并明确记录**：0.2341% 的陆地面积、全部位于海岸/域边界、
对所有通量总量贡献 0.0000%，在分析和出图时排除这 194 个格点。
代价：零重跑，但每一张图、每一个区域统计都要带这个排除说明。

**共同的硬约束**：(a) 和 (b) 都会作废已验收的 A3 初始场并要求重跑 174 年历史。
(c) 不会。

## 第一版（516078）的错误，保留记录

第一版第 5 节报告"七个变量 sentinel 命中 0 / 194"，是错的。
netCDF4 读取时默认套用 `scale_factor`/`add_offset`，而 sentinel 是**原始
短整型**，拿原始值去比已解码的浮点必然全 False。讽刺的是同一行打印的样本
里就有解码后的 sentinel（PSRF −9999.086、FSDS −1111.027、PRECTmms −0.088、
WIND −0.0013428、QBOT 0.0010156）——检查说干净，它自己的证据说不干净。
已修（`set_auto_maskandscale(False)`，并同时打印原始值和解码值以便肉眼复核）。
第 1–4、6 节不受该 bug 影响。
